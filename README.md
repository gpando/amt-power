# amt-power

Minimal Go CLI to change the power state of Intel AMT machines out-of-band
(WS-Man `CIM_PowerManagementService.RequestPowerStateChange` over HTTP Digest
auth, port 16992). The AMT password is stored **encrypted** in a config file
(AES-256-GCM with a passphrase-derived key via scrypt).

## Password Setup

Generate an encrypted config file with `pass set`:

```bash
amt-power pass set [-config ~/.amt-power/config] [-user admin] [-port 16992]
```

You will be prompted for a **passphrase** (min 8 characters) and your **AMT
password**. The passphrase is never stored — it is only needed at runtime to
decrypt the config. You can also provide them via environment variables:

```bash
AMT_PASSPHRASE="my-passphrase" AMT_PASSWORD="amt-secret" amt-power pass set
```

### Config File Format

The config file is a line-based `key = value` format:

```
# amt-power encrypted config
# generated by: amt-power pass set
kdf = scrypt
n = 32768
r = 8
p = 1
salt = <hex>
nonce = <hex>
ciphertext = <hex>
user = admin
port = 16992
```

File permissions are `0600` (owner read/write only), directory `0700`.

### Verify Config

```bash
amt-power pass verify [-config ~/.amt-power/config]
```

Prompts for the passphrase and checks that the config decrypts successfully.

## Usage

```bash
amt-power -ip <IP> [-action on|off|off-hard|reboot|reboot-hard] [-user admin] [-port 16992] [-passphrase <passphrase>]
```

If a config file exists (default `~/.amt-power/config`), the passphrase is
resolved from: `-passphrase` flag > `AMT_PASSPHRASE` env var > interactive
prompt. If no config file exists, falls back to the `AMT_PASSWORD` env var
(deprecated).

### Actions (`-action`, default: `on`)

| Action        | CIM PowerState | Description                                      |
|---------------|----------------|--------------------------------------------------|
| `on`          | 2              | Power on                                         |
| `off`         | 12             | Graceful power off (orderly OS shutdown)         |
| `off-hard`    | 8              | Hard power off (like holding the power button)   |
| `reboot`      | 14             | Graceful reboot (orderly OS reset)               |
| `reboot-hard` | 5              | Power cycle (hard off, then on)                  |

> **Note:** the graceful actions (`off`, `reboot`) are only honored when the
> platform advertises PowerState 12/14 in
> `CIM_AssociatedPowerManagementService.AvailableRequestedPowerStates`. If AMT
> rejects them or nothing happens, fall back to `off-hard` / `reboot-hard`.

### Examples

```bash
# First time setup
amt-power pass set

# Then run normally (passphrase via flag, env, or prompt)
amt-power -ip 10.0.0.90                               # power on (default)
amt-power -ip 10.0.0.90 -action off                    # graceful shutdown
amt-power -ip 10.0.0.90 -action reboot                 # graceful reboot

# With explicit passphrase
AMT_PASSPHRASE="xxx" amt-power -ip 10.0.0.90 -action off-hard

# Legacy (deprecated — shows a warning)
AMT_PASSWORD="xxx" amt-power -ip 10.0.0.90
```

### Quick Run (shell script)

`power.sh` prompts for the passphrase and runs `amt-power` against a fixed IP
(set `AMT_IP` at the top of the script to change it):

```bash
./power.sh              # power on (default)
./power.sh -action off  # graceful shutdown
```

## Build

Run directly from source:

```bash
go run . -ip 10.0.0.90
```

### Cross-compile for all targets

| Binary                       | Target                                     |
|------------------------------|--------------------------------------------|
| `bin/amt-power-mac`         | macOS (Apple Silicon, `darwin/arm64`)      |
| `bin/amt-power-linux-amd64` | Linux x86-64 (`linux/amd64`)               |
| `bin/amt-power-linux-arm64` | Linux ARM64 (`linux/arm64`, e.g. Flint 2)  |

For the Linux targets, CGO is disabled to produce a fully static binary (no
libc/musl dependency) and debug symbols are stripped to minimize size. The
Flint 2 (GL-MT6000) has a MediaTek Filogic 830 (ARM 64-bit) running OpenWrt.

```bash
mkdir -p bin

# macOS (host build)
go build -o bin/amt-power-mac .

# Linux x86-64
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o bin/amt-power-linux-amd64 .

# Linux ARM64 (Flint 2 / OpenWrt)
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -ldflags="-s -w" -o bin/amt-power-linux-arm64 .
```

## Deploy to the Flint 2 router

```bash
# 1. Copy to the router
cat bin/amt-power-linux-arm64 | ssh root@10.0.0.5 "cat > /usr/bin/amt-power && chmod +x /usr/bin/amt-power"

# 2. Generate config on the router
ssh root@10.0.0.5 "/usr/bin/amt-power pass set"

# 3. Run on the router (passphrase via env)
AMT_PASSPHRASE="xxx" /usr/bin/amt-power -ip 10.0.0.90
```
